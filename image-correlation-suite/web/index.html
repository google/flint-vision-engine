Relational Integrity & Architectural Constraints
1 : N cases -> case_evidence_items -> One case container holds multiple evidence items. Multi-case referencing is supported without data duplication.
1 : N media_assets -> case_evidence_items -> One immutable CAS file can be referenced across unlimited cases. Deleting a case never destroys the underlying CAS master asset.
1 : N media_assets -> media_embeddings -> One physical asset can have multi-model vector embeddings (SigLIP-2 NaFlex 768d, SigLIP Base 768d, CLIP 512d) indexed in HNSW for millisecond similarity.
BIT-MATCH migration_manifest -> media_assets -> Strict forensic audit cross-reference. Validates 100% SHA-256 byte parity between source folders and the hex CAS repository.
